# Empirical Evaluation of Feature Selection Stability & Selective Prediction Framework

Исследование влияния методов отбора признаков (Feature Selection) на стабильность валидационной метрики и разработка фреймворка выборочного прогнозирования (Selective Prediction / Abstention) для управления рисками инференса в архитектурах Human-in-the-Loop.

---

## Ключевые результаты (Executive Summary)

1. Стабильность Feature Selection (Тест Левена):
   * Проведена эмпирическая проверка гипотезы о снижении дисперсии метрики ($Accuracy$) при фильтрации шума через SelectKBest(f_classif) на синтетических данных с экстремальной зашумленностью (до 1000 признаков при 20 информативных).
   * Различия в дисперсии метрики между моделями с отбором признаков и без него оказались статистически незначимы ($p > 0.05$) во всех конфигурациях. Градиентный бустинг (LightGBM) устойчив к шумовым признакам на этапе сплитов, однако отбор признаков сократил runtime и расход памяти в ~8–10 раз.

2. Selective Prediction (Контроль риска vs. Покрытие):
   * Построена модель оценки эпистемической неопределенности (Uncertainty Estimation) на основе дисперсии предсказаний деревьев ансамбля RandomForestRegressor.
   * Применение стратегии отсечения неуверенных кейсов снизило медианную относительную процентную ошибку (MDAPE) на наиболее надежных 10% выборки с 0.0332 до 0.0266 (снижение ошибки на 20%).

## Методология и стек

* Стек: Python, LightGBM, scikit-learn, SciPy (Levene Test, Shapiro-Wilk), NumPy, Matplotlib, Seaborn.
* Протокол валидации:
  * Repeated Holdout / Monte-Carlo Cross-Validation ($N=60$ итераций).
  * Строгий контроль Data Leakage: фиттинг селектора признаков выполняется строго внутри каждого тренировочного фолда.
  * Проверка нормальности распределений метрик (Shapiro-Wilk) и робастная проверка однородности дисперсий тестом Левена.
* Стабилизация знаменателя MDAPE: Применено линейное масштабирование $y = y_{\text{raw}} - \min(y_{\text{raw}}) + \sigma(y_{\text{raw}})$ для предотвращения деления на околонулевые значения без искажения относительного порядка ошибок.

## Бизнес-применение (Production Recommendations)

Внедрение концепции Human-in-the-Loop на основе калибровки доверительного порога:
* Консервативный сценарий (Coverage = 60–70%): Модель автоматически обрабатывает до 70% потока с минимальным уровнем риска, а 30% сомнительных объектов отправляются на ручную модерацию экспертами.
* Агрессивный сценарий (Coverage = 85–90%): Отсечение критического хвоста экстремальных ошибок (10–15%) для защиты от финансовых аномалий при сохранении высокой степени автоматизации.
